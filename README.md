# DASHBOARD DE RECURSOS HUMANOS- POWER BI

## Descripción
Proyecto de BI desarrollado en Power BI para analizar indicadores del área de Recursos Humanos mediante un proceso completo de ETL, modelado de datos y visualización

# Objetivo
Transformar datos de Recursos Humanos en información útil para apoyar la toma de decisiones mediante dashboards interactivos.

# Herramientas 
-Excel
-Power BI
-Power Query
-DAX

# Procesos realizados
- Extracción del dataset.
- ETL.
- Creación de tablas de hechos y dimensiones.
- Modelado de datos.
- Creación de medidas DAX.
- Diseño de dashboard interactivo.

# KPIs
- Total empleados
- Empleados activos
- Nivel de satisfacción
- Salario promedio
- Promedio de ausencias
- Años promedio en el puesto
